# Cigarettes-Dairy
A (website) diary to get an overview for cigarettes a day.

## Installation

You need to install [Vendor](https://github.com/composer/composer) and [firebase/php-jwt](https://github.com/firebase/php-jwt) for the php-api.

## Build

To build the project, run:

```bash
npm run build
```

Or use Vite directly:

```bash
npx vite build
```

## Development

To start the development server:

```bash
npm run dev
```
